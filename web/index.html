Grabaciones de la aplicación real, no animaciones: se ve el dataset entrando, el modelo entrenándose y el tablero armándose solo. La única edición es la espera del entrenamiento, que va acelerada.

Recorrido completo. Se sube un archivo, la plataforma lo perfila, se escribe la variable objetivo en castellano y entrena; al final se ve el informe con el modelo campeón, su AUC sobre el holdout ciego y el análisis de variables.

Producto

Todo el trabajo de un equipo de datos, en un programa

Pensado para que lo use quien conoce el negocio, no sólo quien programa. Cada paso queda explicado y auditable.

Datos sin tope de tamaño

CSV, Excel, Parquet o cualquier servidor SQL. El archivo entra por streaming y se consulta fuera de memoria: el límite es el disco, no la RAM.

  • SQL Server, PostgreSQL, MySQL, Oracle, Snowflake
  • Conector de sólo lectura
  • Detecta separador, encoding y decimal solo

ETL automático y explicado

Propone el plan paso por paso con el motivo de cada uno: identificadores, columnas casi vacías, texto que en realidad es número, fechas, atípicos.

  • Auditoría de fuga antes de entrenar
  • Podés aceptar o rechazar cada paso
  • Queda registrado en el informe

El mejor modelo, elegido solo

Escribís el objetivo en un cuadro de texto y compara quince familias de modelos, optimizando variables e hiperparámetros por ti.

  • Clasificación, regresión y multiclase
  • Calibración y corrección del sesgo del monto
  • Importancia de variables y explicabilidad

Tableros que se arman solos

Detecta métricas, dimensiones y la columna de tiempo, y arma KPIs con variación contra el período anterior, gráficos y tabla, todo filtrable.

  • Filtros por fecha y por categoría
  • Se adapta a cualquier dataset o consulta SQL
  • Exportás el tablero filtrado a Excel o CSV

Método

Tres ventanas, para que el número que ves sea el que vas a tener

La trampa más común del machine learning es elegir el modelo mirando el mismo tramo con el que después se reporta el resultado. Acá eso no puede pasar: el tramo con el que se reporta nunca se usó para decidir nada.

01

Entrenamiento

Los modelos aprenden acá, y sólo acá. Ninguna decisión posterior toca este tramo.

02

Selección

Con esta ventana se compara y se elige el campeón, se ajustan hiperparámetros y se calibra.

03

Holdout ciego

Este tramo se abre una sola vez, al final, para reportar. Es el número honesto.

Preguntas

Lo que más nos preguntan

¿Mis datos suben a algún servidor?

No. El programa corre entero en tu equipo: el dataset, el entrenamiento y los informes quedan en tu disco. Lo único que sale a internet es la consulta a la IA, y sólo si vos configurás un proveedor y hacés una pregunta.

¿Hay un tope de tamaño de archivo?

En los planes pagos no. El archivo se convierte a Parquet por bloques y se consulta fuera de memoria, así que el límite práctico es el disco. En la demo el tope es de 50.000 filas por dataset.

¿Necesito saber programar o instalar Python?

No hace falta ninguna de las dos cosas. El instalador trae el motor adentro y la variable objetivo se escribe en castellano en un cuadro de texto.

¿Qué pasa con la licencia si cambio de computadora?

La licencia es un token firmado que podés volver a pegar en el equipo nuevo. Si la perdiste, escribinos y la reemitimos.

¿Se puede conectar a mi base de producción?

Sí, con un usuario de sólo lectura. El conector rechaza cualquier sentencia que escriba antes de mandarla al servidor.

¿Puedo probarlo antes de pagar?

Sí: la demo es el mismo programa, con límite de filas y sin conectores. Los números que muestra son reales, no están degradados.
